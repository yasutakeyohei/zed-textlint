# textlint for Zed

Zed extension for [textlint](https://textlint.github.io/) — pluggable natural language linting.

Runs the [`textlint-lsp`](https://www.npmjs.com/package/textlint-lsp) language server to lint Markdown and MDX files in real time.

## Requirements

```sh
npm install -g textlint-lsp
```
